# meunegocio360-js

Frontend único do MeuNegócio360 (React + Vite + Bootstrap 5).

Como rodar, estrutura de pastas e convenções: [`README.md`](../README.md) da raiz.
Requisitos do frontend: [`docs/requisitos-fe.md`](../docs/requisitos-fe.md).

| Comando          | Para quê                                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------------------- |
| `npm run dev`    | Servidor de desenvolvimento em `http://localhost:5173` (repassa `/api` ao backend em `http://localhost:8080`). |
| `npm run lint`   | ESLint.                                                                                                        |
| `npm run format` | Formata com Prettier.                                                                                          |
| `npm run build`  | Build de produção em `dist/`.                                                                                  |
